# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately, either:

- through GitHub's **[Report a vulnerability](https://github.com/UoA-eResearch/ahoy_training/security/advisories/new)** form on this repository's Security tab (preferred), or
- by email to the security maintainer.

## Security maintainer

| Name | Contact |
|---|---|
| Sean Matheny | [s.matheny@auckland.ac.nz](mailto:s.matheny@auckland.ac.nz) |

Please include a description of the issue, the steps to reproduce it, and the affected files or scripts. We aim to acknowledge reports within a few working days.

## Scope

This repository contains training material and example fine-tuning scripts. Only the latest version on the `main` branch is supported.
